# AGENTS.md

## What this repo is

Hexlet educational project ("Тестирование загрузчика страниц"): a page-loader library plus CLI. Core entry point will be `page_loader.loader.download(url, output_dir)` — fetch an HTML page, download its local images/scripts/styles into a `<page>_files/` directory, and rewrite the HTML to relative paths. Error propagation and the test suite (suppressing side effects, mocking network + filesystem) are the pedagogical focus. README is in Russian; keep user-facing updates consistent.

**Current state is a scaffold**: package config and directory layout exist, but the implementation and tests are placeholders (TODO docstrings). The work is to implement the modules and build the suite.

## Layout

- `page_loader/` — package: `loader.py` (download logic), `names.py` (URL→filename rules), `cli.py` (`page-loader` entry point). All three are stubs to be implemented.
- `tests/` — pytest suite; `fixtures/` holds sample HTML + assets; `test_placeholder.py` keeps the test command green until real tests are written. Tests should stub the network (e.g. `requests-mock`) and use pytest `tmp_path` instead of real disk writes.
- Naming contract (to implement in `names.py`): `https://ru.hexlet.io/courses` → `ru-hexlet-io-courses.html`, resources dir → `ru-hexlet-io-courses_files/`, resource file → `<dir>-<hash-of-resource-url><ext>`. Only same-host resources should be downloaded; external URLs left untouched.

## Commands

Run everything with Poetry; all targets are in the Makefile:

- `make install` — `poetry install`
- `make test` — `poetry run pytest`
- Single test: `poetry run pytest tests/test_loader.py -k resources`
- `make lint` — `poetry run ruff check page_loader tests`
- `make check` — `make selfcheck lint test` (poetry check + lint + tests)

When regenerating `poetry.lock` (dependency changes), rerun `make check`.

## Hard constraints

- `.github/workflows/hexlet-check.yml` is auto-generated by Hexlet (see comment in file, plus `.github/workflows/README.md`). Do not edit, delete, or rename it — Hexlet runs its tests off it on every push. Do not rename the repo either. Makefile/pyproject changes must not touch it.
